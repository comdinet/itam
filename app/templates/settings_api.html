Sending a webhook

In Frappe, add a Webhook on your approval doctype pointing here, with Authorization: Bearer <your token> as a header.

POST https://{{ site }}/api/v1/assets
Authorization: Bearer itam_...
Content-Type: application/json

{
  "item_group": "Overhead headphones",
  "item_name": "ULT900",
  "employee_email": "grace.hopper@yourcompany.com",
  "serial_no": "SN-12345",
  "rate": 129.00,
  "doc_name": "HR-AST-2026-00042"
}

With mappings item_group→category, item_name→name, employee_email→assigned_upn, serial_no→serial, rate→cost and doc_name→external_id, that creates an “Overhead headphones” asset named ULT900 assigned to Grace. Test a token first with GET /api/v1/ping.
