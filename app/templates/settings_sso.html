1. Paste Entra’s metadata

In Entra, on the application’s Single sign-on page, section 3 SAML Certificates, copy the App Federation Metadata Url. It carries the identifier, the login URL and the signing certificate, so this is the only thing worth copying by hand.

If this machine cannot reach Microsoft, download Federation Metadata XML from the same section and paste the file’s contents here instead. Either way it fills in the three fields below, which you can still edit.

It is a real refusal, not a hidden form: the endpoint says no too. It also stands down on its own if the SAML settings are ever cleared, so clearing them can never leave an installation with no way in.

If Entra is down and you need in, the way back is on the server, which is the point — it takes shell access, not a guessable URL:

cd /opt/itam && docker compose exec itam \
  python -c "from app import settings; settings.set_value('ITAM_LOCAL_LOGIN_DISABLED','0','recovery')"

That takes effect immediately — no restart. Keep at least one local admin with a password and two-factor so there is an account to come back to.
